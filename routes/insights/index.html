Skill Tiers

See Exactly Where Every Student Stands

Each topic receives a skill tier — Beginner, Intermediate, Advanced, or Mastery — calculated from accuracy, response time, and problem difficulty. No more guesswork about what to teach next.

  • Trend Indicators

    Every skill is tagged Improving, Declining, or Stable so tutors can spot momentum shifts before they become problems.

  • Staleness Warnings

    Skills practiced 14+ days ago get a warning badge; 30+ days triggers an urgent flag. Keep coverage gaps from hiding in plain sight.

  • Speed Risk Alerts

    Students answering 30% or more slower than their peers are flagged automatically, helping tutors address pacing issues early.

  • Group Insights

    Select up to 8 students and instantly see intersection analysis — shared weak topics, divergent strengths, and common patterns across the group.

Worksheet Generator

Targeted Practice in Seconds

Select the topics a student is struggling with, set the quantity per topic (up to 30 problems), and choose a time limit between 1 and 180 minutes. The generator pulls from the full problem bank to build a custom worksheet instantly.

  • Group Mode

    Generate shared worksheets for multiple students that include only problems all selected students have attempted, ensuring relevance across the group.

  • Real-Time Availability

    See exactly how many problems exist per topic before you generate. No surprises — you always know what's in the bank.

  • Flexible Configuration

    Set per-topic quantities, total time limits, and difficulty preferences to create worksheets that match exactly what the student needs.
